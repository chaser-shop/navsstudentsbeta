Оплата та чек

Номер картки бот підставляє в повідомлення «Дякую за замовлення». Зміна діє для нових замовлень; для старих скористайтесь кнопкою «Надіслати знову».

Знижки за сумою замовлення (опт)

Знижка рахується від суми товарів у замовленні й діє лише для опту. Рівень спрацьовує, коли сума не менша за «Від». Видаліть усі рівні, щоб вимкнути знижки.

Реферальна програма

Клієнт ділиться посиланням зі свого профілю в магазині («Запросити друга»). Друг одразу отримує одноразовий промокод на перше замовлення, а той, хто запросив, — коли перше замовлення друга отримає статус «Виконане». 0 — вимкнути.

Популярні категорії

Встанови власні назви, підписи та зображення для карток на головному екрані.

Промокоди

Знижка в % від суми товарів. Додається до знижки за сумою замовлення. Один клієнт може використати код один раз. Персональні коди рефералки тут не показуються.
