Оплата та чек

Номер картки бот підставляє в повідомлення «Дякую за замовлення». Зміна діє для нових замовлень, а для старих скористайтеся кнопкою «Надіслати знову».

Мінімальні суми та націнка

Покупець не зможе оформити замовлення на меншу суму.

Знижки за сумою замовлення (опт)

Знижка рахується від суми товарів у замовленні й діє лише для опту. Рівень спрацьовує, коли сума не менша за значення «Від». Видаліть усі рівні, щоб вимкнути знижки.

Реферальна програма

Клієнт ділиться посиланням зі свого профілю в магазині («Запросити друга»). Друг одразу отримує одноразовий промокод на перше замовлення, а той, хто запросив, — коли перше замовлення друга отримає статус «Виконане». Значення 0 вимикає знижку.
